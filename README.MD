# 🎓 Student Marks Management System

A simple Python project to manage student marks and view results.

This project takes student details and subject marks as input. It calculates total marks, percentage, grade, and pass/fail result.

---

## ✨ Features

- 👤 Add student name
- 📚 Enter subject names and marks
- 🧮 Calculate total marks
- 📊 Calculate percentage
- 🏆 Show grade
- ✅ Check pass or fail
- 🔍 View student result

## 🚀 How to Run

**Step 1:** Download the Python file.

**Step 2:** Open the file in VS Code.

**Step 3:** Open the terminal and run:

```bash
python3 student_marks_management.py
```

## 📌 Important Notes

- Each subject is out of 100 marks.
- At least 33 marks are required in each subject to pass.
- Student data is stored temporarily.
- Data is lost when the program closes.
